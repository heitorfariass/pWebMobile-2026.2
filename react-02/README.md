# Exercícios de HTML/CSS em React + Next.js

Projeto feito com Next.js (App Router) contendo uma página por exercício.

## Rodar localmente
```
npm install
npm run dev
```

## Deploy no Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Importe o repositório em https://vercel.com/new
3. O Vercel detecta o Next.js automaticamente e faz o deploy.

## Páginas
- `/` — links para os exercícios
- `/exercicio-210` — imagem de fundo + H1
- `/exercicio-231` — DIVs centralizados
- `/exercicio-246` — parágrafo + hyperlinks
- `/exercicio-263` — loja de calçados
